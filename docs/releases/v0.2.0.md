# bettr 0.2.0

bettr 0.2.0 brings the local Issue tracker from its core workflow to a
usable coordination and release-ready tool. This is the first versioned
binary release.

## Highlights

- Link Issues to one or more Git worktrees, attach the current worktree when
  starting or claiming an Issue, and keep worktree history when a worktree is
  detached or becomes inactive.
- Track `blocks` dependencies and one-level parent relations so agents can
  select work without guessing from prose.
- Add agent claims, leases, heartbeats, takeovers, human decision requests,
  event cursors, idempotent writes, and atomic JSON batches.
- Project SQLite audit events to a safe, append-only JSONL log with cursor
  recovery and hash-chain verification. Add archive, rebuild, and explicit
  redaction operations.
- Add SQLite online backup and restore with identity, schema, integrity, and
  foreign-key validation, explicit destinations, confirmation, and audit
  JSONL rebuilding.
- Improve the loopback Web UI with project navigation, Kanban update
  indicators, readable Issue details, and accessible human-decision
  resolution.
- Bind this repository to the `bettr` project through `.bettr.toml` and make
  agent resumption refuse to infer a project when the context is ambiguous.
- Publish native macOS and Linux binaries for x86_64 and arm64 with
  per-archive SHA-256 checksums, a combined `SHA256SUMS` manifest, and
  GitHub artifact attestations.

## Release artifacts

The release workflow publishes archives for:

- `x86_64-unknown-linux-gnu`
- `aarch64-unknown-linux-gnu`
- `x86_64-apple-darwin`
- `aarch64-apple-darwin`

Verify an archive against `SHA256SUMS` before installing it. The existing
`cargo install --path .` workflow remains available for local development,
and the Codex and Claude Code skills remain installable from the repository.
